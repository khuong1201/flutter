## 🚀 Technology Stack

- **Framework**: [NestJS](https://nestjs.com/) (Node.js & TypeScript)
- **Database**: [PostgreSQL](https://www.postgresql.org/)
- **ORM**: [Prisma](https://www.prisma.io/)
- **Documentation**: Swagger OpenAPI
- **Architecture**: Domain-Driven Design (DDD) & Clean Architecture
- **Caching & Locks**: In-memory / Promises (Extensible to Redis)

## 📁 Architecture Overview
This project strictly follows Clean Architecture principles to decouple business logic from framework specific implementations:
- `domain/`: Core business entities, interfaces, and rules.
- `application/`: Use cases handling specific business flows.
- `infrastructure/`: External integrations, Prisma repositories, storage adapters.
- `presentation/`: REST Controllers, Data Transfer Objects (DTOs), and Guards.

## ✨ Implemented Modules & Features

### 1. 🔐 Authentication (`/auth`)
- **JWT-based Auth**: Secure login and registration flows.
- **Social Login**: Ready endpoints to integrate OAuth providers (Google, Apple).
- *Endpoints*: `POST /auth/login`, `POST /auth/register`, `POST /auth/social-login`

### 2. 👤 Users & Gamification (`/users`)
- **Profiles**: Track user XP points, learning targets (HSK/JLPT), and study streaks.
- **Leaderboard**: Global XP leaderboard to drive user engagement.
- *Endpoints*: `GET /users/profile`, `PUT /users/profile`, `GET /users/leaderboard`

### 3. 📚 Curriculum (`/api/v1/levels` & `/api/v1/lessons`)
- **Levels**: Structured roadmaps (e.g., HSK 1, JLPT N5).
- **Lessons**: Categorized modules mapping directly to sets of vocabulary and characters.
- *Endpoints*: 
  - `GET /api/v1/levels` - List all language levels.
  - `GET /api/v1/levels/:id/lessons` - Get lessons for a specific level.
  - `GET /api/v1/lessons/:id/characters` - Get all characters for a specific lesson.

### 4. 🈴 Characters & Language Data (`/characters`)
- **Massive Datasets**: Imported automatically for Chinese (MakeMeAHanzi & CC-CEDICT) and Japanese (KanjiVG & KANJIDIC2).
- **Language Isolation**: Unique constraints (`charText` + `language`) to separate meanings and pronunciations of identical Unicode characters.
- **SVG Stroke Data**: Extremely detailed stroke coordinates and median paths for drawing animations on mobile apps.
- **Smart Audio Lazy Caching Proxy**: Fetches TTS audio dynamically from Google TTS/Pod101 on-demand, caches locally, and redirects instantly to prevent duplicated downloads.
- *Endpoints*: `GET /characters`, `GET /characters/:id`, `GET /characters/:id/audio`

### 5. 🧠 Practice & Spaced Repetition (`/practice` & `/progress`)
- **Spaced Repetition System (SRS)**: Calculates optimal review intervals based on user performance.
- **Quizzes**: Generates dynamic quizzes for lessons.
- **Progress Stats**: Tracks consecutive correct answers and daily due reviews.
- *Endpoints*: 
  - `GET /practice/quiz`, `POST /practice/review`
  - `GET /progress/due`, `GET /progress/stats`

## 🛠 Setup & Installation

### Prerequisites
- Node.js (v18+)
- PostgreSQL

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Create a `.env` file in the root directory:
```env
DATABASE_URL="postgresql://user:password@localhost:5432/course_db?schema=public"
JWT_SECRET="your-super-secret-key"
```

### 3. Sync Database
Apply the Prisma schema to your database:
```bash
npx prisma db push
```

### 4. Import Master Data
Run the custom CLI scripts to seed the database with massive kanji/hanzi datasets, stroke data, and dictionaries.
```bash
# Import SVG strokes (KanjiVG & MakeMeAHanzi)
npm run import:data

# Import Dictionaries (CC-CEDICT & KANJIDIC2)
npm run import:dict

# Generate HSK 1 and JLPT N5 Curriculum
npx ts-node scripts/seed-curriculum.ts
```

### 5. Start the Server
```bash
# Development mode
npm run start:dev

# Production mode
npm run build
npm run start:prod
```
